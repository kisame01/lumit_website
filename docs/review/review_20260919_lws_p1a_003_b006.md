## 5. Four mutations the contract did not ask for — and one of them matters

**R1 — the inline script is gated too, not just the button.** Changing `===` to `==` inside the
script body of `engagements/index.html` (6,399 → 6,398) fires `B-004 header differs from index.html`.
M1 and M2 only proved the *button* is inside the header. **R1 proves the script is.** That is the
stronger form of Constraint 1 and it was worth one mutation to establish.

**R2 — an unterminated `<script>` on one page is now caught.** Deleting `</script>` from
`about/index.html` (6,953 → 6,942) fires B-004. Not because the gate learned to see unterminated
tags — it has not — but because the block no longer matches `index.html`. The §5.4 risk the handover
raised is **narrower than it was**.

**R4 — and here is the hole that is left.** Delete `</script>` from **all six pages identically** and
the gate prints:

```
site check: 6 pages | 68 internal links | 6 assets
site check ok
```

Exit 0, with a broken `<script>` on every page of the site. B-004 compares the six blocks to each
other, so six identical breakages agree perfectly. **This is now the live shape of the risk**, because
this contract deliberately required one block pasted six times, and that is the only way the new
`<script>` will ever be edited. It is the same defect that shipped on `contact/index.html` and it is
the highest-value thing B-007 can close. **Not a defect in this task** — the contract specified the
extraction and the implementer disclosed the residual in §8 — but it is why the gate should be
hardened before the prose pass, which edits all six files at once.

**R3 — the reference-page residual is unchanged.** Delete the toggle from `index.html` (12,862 →
12,753) and the gate emits five `B-004 header differs` lines, one per other page. It goes red loudly,
which is the job, but it reports one defect five times. Known, disclosed in the LWS-P1A-002 review,
untouched by this task.

Every mutated file was restored to its exact pre-mutation byte count and the clean run was
re-confirmed after each.

## 6. The §7 grid — all 84 rows re-measured independently

Six routes × seven widths × two states, served from a local static server, Chromium 1194,
`deviceScaleFactor: 1`.

**`document.documentElement.scrollWidth` equals `clientWidth` in every one of the 84 cells. Zero
horizontal overflow, every width, both states, all six routes.** Defects 1.2 and 1.3 are both gone.

| width | masthead closed | masthead open | toggle | nav closed |
|---|---|---|---|---|

| 1100 | 73.4 | 73.4 | `none` | visible |

Identical on all six routes. **61px closed against §2.1's 80px limit**, down from 290px — the

**The homepage's remaining wide elements are all inside the scroller.** 25 elements on `/` have

viewport. That is the intended horizontal scroller doing its job, not page overflow. The
implementer's note on this is correct and the reviewer confirmed it element by element rather than
taking the claim.

## 9. The implementer's three push-backs — adjudicated

**Line 183, M4's predicted-green column including B-004. The implementer is right and the contract is
wrong.** Pointing a nav `href` at `/nope/` is a change *inside* `<header class="masthead">`, so that
page's block necessarily differs from `index.html` and B-004 must fire. The reviewer reproduced it:
two violations, B-001 at line 34 and B-004 at line 22. **This is a contract defect, not an
implementation defect**, and the implementer did the right thing — it reported the line, did not
touch the check to make the prediction true, and did not hand the task back. RULE 002 held under
pressure. That is the fourth contract in a row where the push-back was worth reading.

**Line 196, "the eleven" heading over a twelve-file list.** Correct, and harmless. The list is the
authority; the count in the heading is a leftover from LWS-P1A-002's eleven site files, which did not
include `scripts/check_site.mjs`.

**Lines 40 and 229, "73px" and "106px" against rendered 73.4 and 105.8.** Correct. Integer rounding in
§1.1's diagnostic table. The reviewer measures the same 73.4 and 105.8. No layout regression.

## 10. Residual risks, carried forward

1. **The identical-six unterminated tag (R4).** The gate cannot see it. Highest priority for B-007.
2. **A reference-page chrome defect reports once per other page (R3).** Unchanged.
3. **46px of no-JS horizontal overflow at 375px.** One CSS line. Next contract.

   visible `:focus-visible` ring, which is the part that matters most.
