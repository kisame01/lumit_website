## 5. Finding — B-008 cannot see files referenced from CSS

**The site set is built from the HTML pages only.** A file referenced by `url()` in `styles.css` —
a self-hosted font, a background image — is in neither set, so leaving it out of `.cpanel.yml` passes
the gate (X4) and the file 404s live. Adding it to `.cpanel.yml` would fail B-008 as "not part of the
site". **B-001 does not read CSS either**, so a misspelt `url()` is also invisible today.

This is a gap in the **contract**, not the implementation — §2.1 rule 7 asked for page `href`/`src`
only, and the coder built exactly that. It does not affect the current site, which has no `url()`.

**The planner handover of 2026-10-08 §7 says "B-008 will refuse the deploy until every font file is in
`.cpanel.yml`". As built, it will not.** Fix: extend `collectAttrs`' reach to `url(...)` in every
stylesheet the pages link, feeding both B-001 and B-008 — in **LWS-P1A-007** if the restyle adds any
`url()`, otherwise as the first part of **LWS-P1A-008**.
